What you get

Everything a competitive client does, in one jar.

Each feature is a switch in the menu. Turn on only what you need.

UI

A menu worth opening

Animated green interface with tabs, expandable settings and sliders. Opens with Right Shift, organised in tabs, and remembers your settings between sessions.

HUD

Move anything

Open Edit HUD, drag any box, snap it to the centre, scroll to resize. Every HUD module has its own scale and background switch.

PvP

PvP assists

Hit Timing, Reach Assist, Totem Warning, Totem Helper and Auto Hit work through simulated key presses, the way a player would press them.

FPS

FPS Boost

One switch caps render and simulation distance and turns off costly extras. Your old settings come back when you switch it off or close the game.

NV

See in the dark

Night Vision, Fullbright and Zoom on a hold key. Set your own FOV with a slider.

ST

Built to stay up

Every module runs inside a safety wrapper, so one bug is logged and skipped instead of crashing your game.

Setup

Playing in three steps.

Works with any launcher that can run Fabric. Prism Launcher is a good choice.

Step 1

Install Fabric

Create an instance for Minecraft 26.1.2 with Fabric Loader 0.19.3 or newer. The game needs Java 25.

Step 2

Add Fabric API

Download Fabric API for 26.1.2 and put it in the mods folder. Emerald Client requires it.

Step 3

Drop in Emerald

Put emeraldclient-2.0.0.jar in mods, start the game and press Right Shift to open the menu.

If you also have the standalone PvP Helper mod, delete it. Its features are now inside Emerald Client.

Questions

Before you download.

Will I get banned on servers?

Some modules (Auto Hit, Crystal Optimizer, Snap Tap, Totem Helper) give an advantage and many servers do not allow them. Read the rules of each server and turn those modules off where they are banned. You are responsible for how you use them.

Does it work with Sodium, Lithium or VulkanMod?

Emerald Client only draws with the normal game GUI and avoids rendering tricks, so it is built to sit next to performance mods. If something clashes, report it with your mod list.

How do I open the menu?

Press Right Shift in game. On the main menu, use the Modules button. You can change the key in Options, Controls.

Can I use it on other Minecraft versions?

This build is for Minecraft 26.1.2 on Fabric. Other versions need a separate build.

Is it affiliated with Mojang or Microsoft?

No. Emerald Client is an unofficial fan-made mod. Minecraft is a trademark of Mojang Studios.

Ready to upgrade your game?

Download the jar, drop it in your mods folder and press Right Shift.
